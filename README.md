# پکیج «پاسخ‌گویی هوشمند» - نصب روی سایت‌های دیگر

این پکیج، همون بخش چت‌بات هوش مصنوعی‌ای هست که برای shinpoosh.ir ساخته شده بود، به‌صورت
کاملاً مستقل و قابل‌نصب روی هر سایت PHP + MySQL دیگه بازنویسی شده. برخلاف نسخه‌ی
شین‌پوش، این نسخه به هیچ جدول یا فایل دیگه‌ای از سایت مقصد وابسته نیست: جدول‌های
دیتابیس، اتصال، و پنل مدیریتش کاملاً مال خودشه.

## این پکیج چیه، چی نیست

- **هست:** یک ویجت چت شناور روی سایت + یک پنل مدیریت مستقل (با رمز عبور جدا) برای
  تنظیم اطلاعات فروشگاه/سایت، فایل راهنما، الگوی پاسخ، لینک ویدیوهای آموزشی، موضوعات
  دانش سایت، و مشاهده‌ی مکالمات و مصرف توکن.
- **نیست:** یک اتصال به جدول‌های اختصاصی شین‌پوش (مثل `arts`/`arts_cat` طرح‌ها، یا
  جدول `pages`). اگه سایت مقصد چنین چیزی داره و می‌خواید هوش مصنوعی ازش استفاده کنه،
  محتواش رو به‌صورت «موضوع» از پنل جدید (بخش «موضوعات دانش سایت») اضافه کنید - همون
  کارکرد رو می‌ده، فقط دستی به‌جای خودکار.

## پیش‌نیازها

- هاست PHP نسخه‌ی ۷٫۴ یا بالاتر، با اکستنشن‌های: `PDO` + `pdo_mysql`، `curl`، `mbstring`.
- یک دیتابیس MySQL/MariaDB (می‌تونه همون دیتابیس سایت اصلی باشه یا یک دیتابیس جدا -
  پیشنهاد می‌شه جدا باشه تا کاملاً مستقل و ایزوله بمونه).
- یک حساب و API Key از سرویس [آوااِی‌آی (avalai.ir)](https://avalai.ir) - این سرویسیه
  که خودِ درخواست‌های هوش مصنوعی رو پردازش می‌کنه (سازگار با فرمت OpenAI).

## مراحل نصب

### ۱. آپلود فایل‌ها

کل پوشه‌ی `ai-chat-widget` رو در سایت مقصد آپلود کنید - مثلاً در ریشه‌ی سایت یا داخل
یک زیرپوشه (مثلاً `public_html/ai-chat/`).

### ۲. ساخت فایل تنظیمات

فایل `config.example.php` رو کپی کنید و اسمش رو بذارید `config.php` (کنار همون فایل).
داخلش این مقادیر رو با اطلاعات هاست خودتون پر کنید:

- `AICHAT_DB_HOST` / `AICHAT_DB_NAME` / `AICHAT_DB_USER` / `AICHAT_DB_PASS`: اطلاعات
  اتصال به دیتابیس (از پنل هاست/cPanel قابل ساختن).
- `AICHAT_ADMIN_PASSWORD`: یک رمز عبور طولانی و دلخواه برای ورود به پنل مدیریت این بخش.
- `AICHAT_BASE_URL`: آدرس کامل سایتی که این پکیج روش نصب می‌شه، با اسلش انتهایی
  (مثلاً `https://example.com/` یا `https://example.com/ai-chat/` اگه در زیرپوشه‌ست).

**امنیت مهم:** بعد از ساخت config.php، از دسترسی مستقیم مرورگر بهش جلوگیری کنید - چون
رمز دیتابیس و رمز پنل ادمین توشه. ساده‌ترین راه: یک فایل `.htaccess` کنار config.php
با همین محتوا بسازید:

```
Deny from all
```

(روی Apache/cPanel معمولاً کافیه. اگه هاستتون Nginx هست، از پشتیبانی هاست بخواید
دسترسی به config.php رو مسدود کنه.)

### ۳. ساخت جدول‌های دیتابیس

نیازی به اجرای دستی SQL نیست - همین که برای اولین بار وارد پنل مدیریت بشید (مرحله‌ی
بعد)، جدول‌های لازم (`aichat_settings`، `aichat_conversations`، `aichat_messages`،
`aichat_topics`، `aichat_videos`) خودکار ساخته می‌شن.

### ۴. ورود به پنل مدیریت و تنظیمات اولیه

آدرس `.../ai-chat-widget/admin/settings.php` رو باز کنید (اگه در زیرپوشه نصب کردید،
مسیرش عوض می‌شه). با رمزی که در `AICHAT_ADMIN_PASSWORD` گذاشتید وارد بشید و:

1. تیک «فعال باشد» رو بزنید.
2. API Key سرویس آوااِی‌آی رو وارد کنید.
3. اطلاعات کلی سایت/فروشگاه (ساعات کاری، نحوه‌ی ارسال، تماس و ...) رو در «اطلاعات
   کلی» بنویسید.
4. اختیاری: فایل راهنمای txt، الگوی پاسخ‌گویی، رنگ‌ها و عنوان ویجت رو هم تنظیم کنید.
5. اختیاری: چند «موضوع دانش سایت» (از منوی بالا) و لینک‌های ویدیوی آموزشی اضافه کنید.

### ۵. اضافه کردن ویجت به قالب سایت

در فایل قالب سایت مقصد که در همه‌ی صفحات لود می‌شه (معمولاً یک فایل مثل `footer.php`
یا انتهای `<body>` در قالب اصلی)، این خط رو درست قبل از `</body>` اضافه کنید:

```php
<?php include '/مسیر/کامل/تا/ai-chat-widget/widget.php'; ?>
```

اگه سایت مقصد از jQuery استفاده نمی‌کنه، یک خط قبل از این include اضافه کنید:

```html
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
```

همین! ویجت فقط وقتی از پنل «فعال» باشه نمایش داده می‌شه.

### ۶. تست

- یک پیام در ویجت چت بفرستید و مطمئن بشید پاسخ می‌گیرید.
- صفحه رو رفرش کنید - پیام‌های قبلی باید بمونن (تا ۲۴ ساعت حفظ می‌شن).
- از پنل، آمار مصرف توکن و لیست مکالمات رو چک کنید.

## نکات امنیتی

- `config.php` رو حتماً پشت `.htaccess` (یا یک پوشه بالاتر از ریشه‌ی وب) محافظت کنید.
- رمز `AICHAT_ADMIN_PASSWORD` رو طولانی و غیرقابل‌حدس انتخاب کنید و جایی ننویسیدش که
  در دسترس دیگران باشه.
- پیام‌های کاربر قبل از ذخیره پاکسازی (sanitize) می‌شن و همه‌ی کوئری‌های دیتابیس با
  prepared statement نوشته شدن (در برابر SQL Injection ایمن).
- API Key سرویس آوااِی‌آی فقط در دیتابیس ذخیره می‌شه و هیچ‌وقت به مرورگر کاربر فرستاده
  نمی‌شه.
- یک محدودکننده‌ی نرخ ارسال (rate limit) داخلی هست: هر IP حداکثر ۲۰ پیام در ۱۰ دقیقه.

## سفارشی‌سازی

- **رنگ و عنوان ویجت:** از پنل تنظیمات → بخش «ظاهر ویجت» قابل تغییره (بدون نیاز به
  دست‌زدن به کد).
- **حذف مرحله‌ی دریافت نام/شماره موبایل:** اگه نمی‌خواید بعد از اولین پیام از کاربر
  نام/شماره بپرسه، در `widget.php` بخش `#ai-chat-lead` رو حذف کنید و در `api.php`
  بلوک `if (!$is_first) { ... }` (داخل اکشن `send`) رو کامنت/حذف کنید.
- **زبان/متن‌ها:** همه‌ی متن‌های فارسی مستقیم در `widget.php` و `admin/*.php` قابل
  ویرایشن.
- **استایل CSS:** استایل ویجت داخل `widget.php` (تگ `<style>`) و استایل پنل داخل
  `admin/_header.php` هست - هر دو مستقل و آسون برای تغییر.

## عیب‌یابی متداول

| مشکل | راه‌حل |
|---|---|
| پیام «این بخش در حال حاضر فعال نیست» | تیک «فعال باشد» رو در تنظیمات بزنید و API Key رو وارد کنید. |
| «اکستنشن cURL روی سرور فعال نیست» | از پشتیبانی هاست بخواید اکستنشن `curl` رو در PHP فعال کنه. |
| خطای اتصال به دیتابیس (صفحه‌ی سفید یا خطای PDO) | مقادیر `AICHAT_DB_*` در config.php رو دوباره چک کنید. |
| ویجت اصلاً نمایش داده نمی‌شه | مطمئن بشید include مسیر درستی به widget.php داره، و jQuery قبلش لود شده. |
| پاسخ‌ها ربطی به اطلاعات وارد شده ندارن | مطمئن بشید متن رو در «اطلاعات کلی» یا «موضوعات دانش سایت» ذخیره کرده باشید (نه فقط در ذهنتون!). |

## ساختار فایل‌ها

```
ai-chat-widget/
├── config.example.php      ← کپی کنید به config.php و ویرایش کنید
├── widget.php               ← ویجت چت (include در قالب سایت)
├── api.php                  ← endpoint عمومی چت (به چیز دیگه‌ای نیاز نداره)
├── includes/
│   └── ai_chat_lib.php      ← کتابخانه‌ی اصلی (منطق پاسخ‌گویی، جستجو، دیتابیس)
└── admin/                    ← پنل مدیریت مستقل (رمز جدا از بقیه‌ی سایت)
    ├── login.php / logout.php
    ├── settings.php / save_settings.php
    ├── topics.php            ← موضوعات دانش سایت
    ├── videos.php             ← لینک‌های ویدیوی آموزشی
    └── conversations.php / conversation.php
```
